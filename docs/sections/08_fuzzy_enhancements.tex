\section{Fuzzy-Enhanced Risk Management and Action Smoothing}

To address the limitations of the threshold-based risk mechanisms used in our initial
environment design, we incorporate a Mamdani-style Fuzzy Inference System (FIS).
The previous implementation relied on hard thresholds, particularly for market
turbulence, which could abruptly suppress buying actions and introduce discontinuities
in the agent's behavior. The fuzzy system replaces these hard decisions with smooth,
continuous membership functions that allow the agent to adapt more gradually to changing
market conditions.

The fuzzy framework consists of two independent components: an Action Smoother and a
Reward Shaper.

\subsection{Fuzzy Action Smoothing}

In the original environment, actions were constrained whenever turbulence
$\tau_t$ exceeded a predefined threshold $\tau_{thr}$, enforcing the rule

\[
a_t' = \min(a_t, 0).
\]

This mechanism completely blocked buying actions during periods of high turbulence.
While effective as a risk-control measure, it introduced abrupt changes in the action
space and could make learning more difficult. The Fuzzy Action Smoother replaces this
binary rule by mapping the raw action component $a_i \in [-1,1]$ produced by the policy
network and the current turbulence value $\tau_t$ to a risk-adjusted action
$a_{t,\text{safe}}$.

The inputs are fuzzified using overlapping triangular and sigmoidal membership
functions, shown in Figure~\ref{fig:action_smoother_mfs}. The input spaces are defined as:

\begin{itemize}
    \item \textbf{Raw Action ($a_i$):} Divided into the linguistic states
    $\mathcal{A} = \{\text{Sell}, \text{Hold}, \text{Buy}\}$.
    
    \item \textbf{Market Turbulence ($\tau_t$):} Divided into the linguistic states
    $\mathcal{T} = \{\text{Low}, \text{Medium}, \text{High}\}$.
\end{itemize}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.95\textwidth]{figures/action_smoother_mfs.png}
    \caption{Membership functions for the Fuzzy Action Smoother, defining the partitions
    for the raw action input $a_i$ (left) and the market turbulence index $\tau_t$
    (right).}
    \label{fig:action_smoother_mfs}
\end{figure}

The rule base is designed to reduce risk-taking behavior as market turbulence increases:

\begin{align*}
    \mathbf{R}_1: & \text{ IF } \tau_t \text{ is High } \Longrightarrow a_{t,\text{safe}} \text{ is Sell} \\
    \mathbf{R}_2: & \text{ IF } \tau_t \text{ is Medium } \wedge a_i \text{ is Buy } \Longrightarrow a_{t,\text{safe}} \text{ is Hold} \\
    \mathbf{R}_3: & \text{ IF } \tau_t \text{ is Medium } \wedge a_i \text{ is Sell } \Longrightarrow a_{t,\text{safe}} \text{ is Sell} \\
    \mathbf{R}_4: & \text{ IF } \tau_t \text{ is Low } \Longrightarrow a_{t,\text{safe}} \text{ acts as } a_i
\end{align*}

The final action value is obtained using centroid defuzzification, producing a continuous
risk-adjusted action that replaces the previous threshold-based constraint.

\subsection{Fuzzy Reward Shaping}

The original reward function included a linear volatility penalty term,
$-\lambda e_t v_t$, where portfolio exposure and market volatility directly reduced
the reward. Although simple, this penalty could become excessively large during periods
of elevated volatility and reduce the distinction between good and poor trading
decisions. To address this issue, the Fuzzy Reward Shaper maps portfolio exposure
$e_t$ and the Market Volatility Index ($v_t$) to a non-linear penalty factor
$\phi_t \in [0,1]$.

The input variables are partitioned as shown in
Figure~\ref{fig:reward_shaper_mfs}:

\begin{itemize}
    \item \textbf{Portfolio Exposure ($e_t$):} Divided into
    $\{\text{Low}, \text{High}\}$.
    
    \item \textbf{Volatility Index ($v_t$):} Divided into
    $\{\text{Calm}, \text{Stressed}, \text{Panic}\}$.
\end{itemize}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.95\textwidth]{figures/reward_shaper_mfs.png}
    \caption{Membership functions for the Fuzzy Reward Shaper, showing the state
    partitions for portfolio exposure $e_t$ (left) and the VIX volatility metric
    $v_t$ (right).}
    \label{fig:reward_shaper_mfs}
\end{figure}

The rule base increases the penalty only when both exposure and market volatility are
high:

\begin{align*}
    \mathbf{R}_5: & \text{ IF } v_t \text{ is Panic } \wedge e_t \text{ is High } \Longrightarrow \phi_t \text{ is Severe} \\
    \mathbf{R}_6: & \text{ IF } v_t \text{ is Stressed } \wedge e_t \text{ is High } \Longrightarrow \phi_t \text{ is Medium} \\
    \mathbf{R}_7: & \text{ IF } v_t \text{ is Calm } \vee e_t \text{ is Low } \Longrightarrow \phi_t \text{ is None}
\end{align*}

After defuzzification, the resulting penalty factor modifies the reward function as

\[
    r_t =
    \log\left(\frac{V_{t+1} + \epsilon}{V_t + \epsilon}\right)
    -
    (\phi_t \cdot \lambda_{scale}).
\]

This formulation applies stronger penalties only when market conditions and portfolio
risk justify them, while maintaining a weaker penalty in lower-risk situations.

Overall, the fuzzy logic framework replaces fixed threshold-based controls with
continuous risk-adjustment mechanisms. The Action Smoother modifies trading decisions
according to market turbulence, while the Reward Shaper adjusts risk penalties based on
both market volatility and portfolio exposure. Together, these components provide a
more gradual and context-dependent approach to risk management within the reinforcement
learning environment.
